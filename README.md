# Mengjia Zhang (张梦佳) - Academic Profile

一个专业的个人学术主页，展示学术信息和联系方式。

## 项目结构

```
zhang-mengjia.github.io/
├── index.html          # 主页
├── css/
│   └── style.css       # 样式文件
├── assets/
│   ├── avatar/         # 头像文件夹
│   │   └── avatar.jpg
│   ├── images/         # 图片资源
│   │   └── icon.png
│   └── docs/           # 文档资源
├── README.md           # 项目说明文档
└── ...

```

## 功能特性

- 📱 **响应式设计** - 支持多种设备屏幕尺寸
- 🎨 **主题切换** - 支持明暗主题切换
- 🖼️ **头像轮播** - 可扩展的头像轮播功能
- 📋 **联系方式** - 集成多种联系方式卡片
- 🖨️ **打印导出** - 支持打印到 PDF 功能

## 技术栈

- HTML5
- CSS3
- JavaScript (Vanilla)
- Responsive Design

## 快速开始

1. 克隆或下载项目到本地
2. 在浏览器中打开 `index.html` 文件即可查看

## 自定义

### 修改基本信息
在 `index.html` 中修改以下部分：
- 标题和名称
- 职位信息
- 个人简介

### 添加头像
将新的头像文件放入 `assets/avatar/` 文件夹，然后在 `index.html` 中取消注释相应的代码行并更新路径。

### 修改样式
编辑 `css/style.css` 文件以自定义网站外观。

## 文件说明

| 文件/文件夹 | 说明 |
|-----------|------|
| `index.html` | 网站主页文件 |
| `css/style.css` | 网站样式表 |
| `assets/avatar/` | 头像存储目录 |
| `assets/images/` | 其他图片资源目录 |
| `assets/docs/` | 文档资源目录 |

## 主题切换

点击菜单栏中的 "View (Switch Theme)" 可在亮色和暗色主题之间切换。

## 打印功能

点击菜单栏中的 "File (Print to PDF)" 可将网页打印为 PDF 文件。

## 浏览器兼容性

支持现代浏览器（Chrome、Firefox、Safari、Edge 等）
